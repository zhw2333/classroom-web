# 人脸考勤开发与验证记录

基线：sam28403/classroom-web main 8d4c4152360fc04958f0b3e7b2a6a7bfa33eb924。

新增：教师完整考勤名单、状态汇总、搜索筛选、手动及每 5 秒刷新；未签到学生使用 unrecorded，结束后记 absent；保留人工登记与复核。
后端：只允许服务端记录的安卓会话签到；只登记管理员审核通过的当前头像；换头像后下次登记自动更新，识别中头像变化则拒绝落库；旧客户端自传的登记照片不会成为比对基准。现有头像首次使用会自动补建资料，不需要数据库结构变更。

验证：npm run build 通过。npm test 共 76 项，75 通过、1 项 MySQL 环境测试跳过，无失败。另通过 Chrome 浏览器教师端流程：发起、完整名单、自动更新、搜索、筛选和结束补记缺勤。新增集成测试覆盖安卓端限制、伪造端类型 Header、独立同意、无头像、客户端替换登记照片、审核头像字节一致、换头像同步、其他人脸、服务故障不落库、识别中头像更换、重复签到和教师越权。

命令：
```
npm ci
npm test
npm run build
node --test tests/e2e/attendance-browser.test.js
npm run demo:full
```
浏览器测试需要本机 Google Chrome。启动前按 .env.example 配置管理员密码和 CompreFace 两种服务密钥。

限制：识别服务在集成测试中使用协议替身；教师浏览器测试通过接口准备签到记录以验证页面更新。未将替身结果视为真实人脸识别验收。安卓拍照界面由移动端同学完成；真实 CompreFace、MySQL 和安卓真机仍需共同联调。不含活体检测，不做考勤名单快照。异常签到沿用原规则，提交后由教师复核，不能直接再次提交；服务故障允许重试。
